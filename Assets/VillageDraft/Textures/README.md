# Ground and route textures

The five 1K albedo/normal pairs in `PolyHaven/` are from [Poly Haven](https://polyhaven.com/), released under [CC0](https://polyhaven.com/license). They are used for village ground, stone paths, boardwalks, gravel, and sand. "Powered by Poly Haven" credit is included here for the API used during development.

| Material | Poly Haven page |
| --- | --- |
| Leafy grass | https://polyhaven.com/a/leafy_grass |
| Cobblestone Floor 04 | https://polyhaven.com/a/cobblestone_floor_04 |
| Gravel Ground 01 | https://polyhaven.com/a/gravel_ground_01 |
| Brown Planks 07 | https://polyhaven.com/a/brown_planks_07 |
| Sand 02 | https://polyhaven.com/a/sand_02 |

The Unity builder applies these as tiled URP/Lit maps. Keep the paths stable when regenerating the scene.
