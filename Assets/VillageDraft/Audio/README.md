# Village audio

These WAV files are procedurally synthesized by `generate_audio.py`. They are AI-assisted project assets, not student-made recordings. Declare them as such in any coursework asset disclosure.

The cues are gentle, short, mono 22.05 kHz clips for action success, venue completion, and whole-village completion. The 24-second ambient loop is intentionally quiet and can be muted in the scene's `VillageAudioDirector` component.
